## 할 수 있는 일

- **제품 찾기**: 형명 · 제품코드 · 치수 · 용량 · CCA · 고객 품번을 섞어서 한 번에 검색
- **제품 페이지**: 성능 · 납 중량 · 실제 CAD 3D · 라벨 붙여 보기(전조 앞/뒤 · 카바 윗면) · 판매 현황 · 파렛트 적재 기준 · 극판 표준화
- **RFQ 1·2·3안 매칭**: 고객 양식 엑셀을 그대로 올리면 조건대로 제품을 골라 채움 (100건 약 0.2초, 실측)
- **견적 → 컨테이너 적재 계산**: 견적 목록의 제품 · 수량으로 20ft / 40ft 컨테이너 적재를 바로 계산
- **거래처 · 바이어 표기 검토**, **3D 분해 설명**, 영어 · 일본어 화면
- 1920 · 4K · 5K 와이드 화면 맞춤
